# CV Rizma Ananda Sari — Industrial Theme

Website CV statis menggunakan HTML, CSS, dan JavaScript murni. Dirancang dengan tema manufaktur industri: hijau lime, charcoal, grid teknis, visual gear, dan tata letak responsif.

## Isi folder

- `index.html` — struktur dan konten CV
- `style.css` — desain, layout responsif, dan animasi
- `script.js` — menu mobile, tombol salin email, dan tahun footer
- `README.md` — panduan ini

## Menjalankan secara lokal

1. Ekstrak folder atau simpan semua file di satu folder.
2. Buka `index.html` di browser.
3. Untuk hasil font yang sama seperti desain, koneksi internet diperlukan karena Google Fonts digunakan. Website tetap dapat dibuka jika font eksternal tidak tersedia.

## Deploy gratis melalui GitHub Pages

1. Login ke [GitHub](https://github.com/) dan buat repository baru. Contoh: `cv-rizma-ananda-sari`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke **root** repository (bukan di dalam folder lain).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website, biasanya:
   `https://USERNAME.github.io/cv-rizma-ananda-sari/`
7. Jika ingin alamat `https://USERNAME.github.io/`, nama repository harus `USERNAME.github.io`.

## Kustomisasi

- Edit teks CV di `index.html`.
- Ubah warna pada variabel di bagian `:root` dalam `style.css`.
- Kontak telepon dan email diatur pada `index.html`; email untuk tombol salin juga ditetapkan di `script.js`.
- Tidak membutuhkan framework, build step, backend, atau API key.

## Catatan penting sebelum publikasi

CV sumber mencantumkan tanggal pengalaman PT Denso dalam dua versi: `Sep 2022 – June 2026` dan `September 2022 – Agustus 2026`. Website menggunakan `September 2022 – Agustus 2026` mengikuti uraian pengalaman yang lebih rinci, dengan catatan untuk diverifikasi. Pastikan tanggal akhir yang benar sebelum website dipublikasikan.

Istilah `cokotei` pada deskripsi QCC dipertahankan seperti tertulis di CV sumber; periksa ejaan/istilah teknis yang dimaksud sebelum dipublikasikan.

Informasi kontak dipublikasikan di website. Pastikan pemilik CV setuju agar nomor telepon dan email dapat diakses publik.
